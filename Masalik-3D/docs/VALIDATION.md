# Native validation — 2026-11-10

## Executed locally

Godot 4.6.3.stable.official.7d41c59c4, Linux headless, Jolt, fixed physics timestep 60 Hz. **153 checks, zero failures.** Test source: `tests/headless_test_runner.gd` and scene. Full native UI smoke scene also completes without script errors.

Checks cover script compilation, ten original vehicle specs, five chapter / 25 story / 65 overall mission records, map endpoints, actual Curve3D length >=15 km, sector load/unload bounds across all six regions, real rigidbody suspension/acceleration/RPM/braking/reverse, drivetrain selection, independent touch pointers, simultaneous steering/gas, input reset, atomic save/recovery/migration/import rejection, nonduplicated rewards, ten visible wheel rigs and bundled audio loads.

UI smoke instantiates native region menus, garage, settings, credits, all mission tabs and briefing, then the real game scene, pause/resume, layout editor, map and photo UI. This detects runtime script failures; it is not a visual usability or Android touch acceptance test.

## Scope and limitations

| Requirement | Current implementation / validation |
|---|---|
| Native engine/startup | Repaired and boots; no WebView |
| Offline runtime | Local code/resources only; Android manifest verification in CI; physical airplane-mode first launch pending |
| 15 km connected map | Measured continuous centerline and streamed collidable road/terrain; not driven end-to-end on device |
| Six regions | Native sectors with environment variants; artistic fidelity still an early procedural style |
| Ten cars | Original full spec catalog and parameterized local visible meshes; production-quality interior/exterior art remains incomplete |
| Physics | Real Jolt rigidbody suspension and contact forces tested on flat ground; slope/surface long-driving acceptance pending |
| Assists | Grip/traction limiting and stabilization available; independently validated production ABS/TCS/ESC models not complete |
| Garage | Paint, rim color, tire compound, ride height, engine upgrade and purchase logic; roof/accessory options incomplete |
| Missions | Original 65 records and narrative retained, endpoint/integrity/reward state implemented; all 65 driving completions not tested |
| Rescue | Physical towing force/attachment implementation; complete towing mission playthrough pending |
| Controls | Multi-touch wheel and pedals, alternative controls, three layouts; every auxiliary HUD button is not yet editable |
| Cameras | Six positions/orbit, collision query, local photo path; cabin art and Android photo sharing/export need acceptance |
| Traffic | Eight pooled CharacterBody cars with path/obstacle checks; dense-traffic behavior needs road testing |
| Weather/audio | Native time, sun, fog/rain/grip and local synthesized music/effects; separate thunder/gear-change/sea ambience polish incomplete |
| Performance | Three quality levels, bounded sectors, instancing/culling; measured Android FPS, thermal and 30-minute stability pending |
| Build/signing | CI build path and APK metadata checks; production key continuity cannot be established without owner's key |

No synthetic FPS claims, no claimed physical phone test, no claimed final 1.0 acceptance. A headless fixed-step simulation is not a 30-minute device performance test. Actual runtime evidence, when generated by CI, comes from the game scene, not an image mockup. Final high-fidelity art, remaining systems and device acceptance must be finished before a stable release.

## Visual regression found and repaired

The first CI APK (593a989) rendered the car falling below the map: road/terrain triangles were wound backward. The flat-ground physics unit checks had not covered the actual road. That artifact is not a release candidate. Reversed triangle winding and added seven actual-road suspension/nonpenetration checks spanning all six regions. All fourteen additional assertions now pass. Subsequent CI must rebuild the corrected source and capture fresh visual evidence.
